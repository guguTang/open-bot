## 已知限制
- 本地 vLLM tools：需 `--enable-auto-tool-choice` + `--tool-call-parser hermes`；否则 runtime 对本轮自动降级为无 tools 补全（聊天仍有回复，但不调工具）
- ListMachines + host_*：登记/列表/心跳 + 桌面 exec；`host_ls` 浅层浏览；聚合用 host-file-query；浏览器不登记为电脑；沙箱对用户透明，内部路由仍为 `/v1/sandbox*`
- 一期 JWT/密钥为开发默认值，生产必须改 `JWT_SECRET`；内部总线令牌默认 `INTERNAL_TOKEN=open-bot-dev-internal`
- LLM `api_key` 库内明文存储，仅 API 脱敏回传（未做 KMS 加密）
- 助手 `system_prompt` 与 runtime 内置 persona 拼接，需注意长度
- Skills：全局只读 + 用户可上传自定义（仅能删自己的）；name 须符合 Agent Skills（小写/数字/连字符）；**Bot 允许列表**与用户启用取交集
- 记忆语义召回依赖 pgvector 与 `EMBEDDING_*`；扩展或嵌入服务不可用时自动降级关键词
- 从旧 `postgres:16` 升级到 pgvector 镜像时，开发库需删卷重建（`deploy_openbot_pg`）
- 压缩：主触发为 token 预算（可 per-connection `context_window`）；遗留消息/字符阈值仍仅 env；Web 设置页只读展示
- 协作总线：priority 可异步唤醒；默认不把 inbox 注入对话上下文；tools 默认关闭时仍可用 JWT HTTP + WS；工具路径代码已接内部 API（`OPENBOT_API_URL` / `INTERNAL_TOKEN`）
