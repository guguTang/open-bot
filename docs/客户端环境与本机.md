# 客户端环境与本机（Phase 1）

> 目标：Bot 知道用户在哪个客户端；**沙箱/运行环境对用户透明**（只见预览、下载、回复）；能列出已注册主机（ListMachines 风格）。  
> **账户共享工作电脑（team）**：多 Bot 共用 `shared/` + 各自 `bots/{agent_id}/`；Bot 可设 `computer_mode=private` 使用私有目录。见 [沙箱电脑.md](./沙箱电脑.md)。  
> **本机工具**：桌面端已接通 `host_ls` / `host_read` / `host_write` / `host_shell` 等（按 `machine_id` 路由）；聚合查询见 [本机查询与Skills设计.md](./本机查询与Skills设计.md)。
> 注意：产品文案避免对用户说「工作电脑」架构词；开发文档可用 team/private 术语。

## 产品语言（必读）

- **用户可见**：浏览器 / macOS / Windows / 移动端是客户端；已注册主机是「我的电脑」。结果以预览、下载、回复呈现。
- **禁止教用户**：sandbox / Docker / 容器 / `/workspace` /「工作电脑」/「第二台电脑」等架构说法。
- **内部可保留**：API 路由 `/v1/sandbox*`、工具名 `sandbox_*`、开发文档中的沙箱术语；设置「当前 Bot」可用「电脑模式 team/private」面向高级用户。
- 设置页高级区可称 **「运行环境（高级）」**（面向排障），正文避免向普通用户解释 Docker/沙箱。

## 客户端信封（client）

每条聊天发送在 `POST /v1/conversations/{id}/messages` body 中带 `client`，经 Go 转发到 Python `RunRequest.client`：

```json
{
  "platform": "web|macos|windows|linux|ios|android",
  "app": "browser|tauri|capacitor",
  "os": "darwin|win32|linux|ios|android|…",
  "arch": "arm64|x64|…",
  "app_version": "0.1.0",
  "locale": "zh-CN",
  "capabilities": {
    "host_tools": false,
    "workspace_tools": true
  }
}
```

| 运行形态 | platform | app | 是否登记为「电脑」 |
|----------|----------|-----|-------------------|
| 普通浏览器 | `web` | `browser` | 否 |
| Tauri 桌面（复用 web UI） | `macos`/`windows`/`linux` | `tauri` | 是（登录后 register + heartbeat） |
| Capacitor 移动 | `ios`/`android` | `capacitor` | 是（可选） |

检测模块：`apps/web/src/lib/clientEnv.ts`（`__TAURI__` / Capacitor / UA）。  
System prompt 注入 **「环境」** 块：如何解释「我的电脑」、内部 `sandbox_*` ≠ Downloads，且禁止向用户泄露架构。

## 路由表（tools 开启时）

| 用户意图 | 正确路径 |
|----------|----------|
| 当前几点 / 算一下 / 拉个公开网页 | `get_current_time` / `calculator` / `http_fetch` |
| 加载技能说明 | 目录 + `load_skill` |
| 跑脚本、写临时文件、生成可预览内容 | `sandbox_*`（对用户只谈结果，不提环境） |
| 「我的电脑 / Downloads / 桌面 / 我有哪些电脑」 | 先 `list_machines` |
| 本机读文件 / 浅层列目录 | `host_ls`（浅层；可选 limit/sort/glob）/ `host_read` |
| 本机聚合查询（最大/按扩展名） | `load_skill host-file-query` → `host_shell` 跑脚本或只读 find/du |
| 本机命令 / 打开软件 | `host_shell`（Auto-review：无白名单，风险命令确认 / 硬拒绝 / 其余自动）/ `host_open` |
| 看本机屏幕 | `host_screenshot`（仅 macOS 桌面；JPEG 附在工具结果里，模型下一轮能看见）。不要用 `screencapture` 存路径。屏幕录制被拒时引导用户到系统设置 |
| 网页且无注册主机 | 如实说明无法访问本机，**不要**用内部运行环境冒充 |

对用户禁止说：sandbox / Docker / 容器 / `/workspace` /「工作电脑」。内部 API 路由仍可用 `/v1/sandbox*`。

## ListMachines MVP

### DB

表 `user_machines`：`id`, `user_id`, `machine_key`, `label`, `platform`, `os`, `arch`, `app`, `app_version`, `status`, `last_seen`, …

### HTTP（JWT）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/v1/machines` | 列出当前用户机器（超时未心跳 → offline） |
| POST | `/v1/machines/register` | 按 `machine_key` upsert 自身；**首次**用客户端设备名作 `label`，再次注册不覆盖已改名 |
| PATCH | `/v1/machines/{id}` | 重命名（`{ "label": "…" }`，最长 64 字）；全端可见 |
| POST | `/v1/machines/{id}/heartbeat` | 刷新 online / last_seen |
| DELETE | `/v1/machines/{id}` | 删除 |
| POST | `/internal/machines/list` | runtime 工具用（`X-Internal-Token` + `user_id`） |

默认设备名：Tauri 读 OS 电脑名（macOS ComputerName / hostname）；Capacitor 用 Device 插件名（有则）；浏览器不登记主机，聊天信封用「Chrome · macOS」类回退。聊天 `client` 带 `machine_id` + `machine_label`；环境块优先用服务端 `label`，并列出其它已登记电脑名称。

### Tool

`list_machines`：返回 label / platform / connected。  
`host_ls` / `host_read` / `host_write` / `host_delete` / `host_move` / `host_open` / `host_screenshot` / `host_shell`：经桌面 exec 通道在目标机执行。  
`host_screenshot`：`op=screenshot`，`path` 为 `main`（默认）或 `all`，`dest` 为可选的显示器序号（从 1 起）。macOS 用 `screencapture` 截 JPEG，压到约 1.2MB 以内，以 `image_base64` 返回。Runtime 在发给模型前把像素拆成 `image_url` 内容块（工具消息正文仍是不含像素的 JSON）。其它系统返回 `unsupported_platform`。屏幕录制未授权时返回 `screen_recording_denied`，不重试。Auto-review 与 `host_open` 一样按只读自动放行（`exec_policy=ask` 或自动审核关闭时仍确认）。手机 / 浏览器 `host_tools=false`，不能当截屏主机。桌面设置 → 电脑在 macOS 上提供「屏幕录制 / 辅助功能」入口。  
`host_ls`：浅层浏览（默认约 50 条，可 `sort`/`glob`，响应含 `truncated`）；找最大文件请用 `host-file-query` + `host_shell`。

### UI

设置 → **运行环境（高级）**（内部 sandbox 排障）+ **电脑**（在线/离线列表、重命名）。  
聊天 Artifact 卡片展示友好文件名（如 `tetris.html`），动作为「打开文件」，不展示 `/workspace/…`。

## 验收

1. 重启 `make dev-api` / `make dev-runtime`（迁移自动建表）。
2. 浏览器发消息：run payload 含 `client.platform=web`；问「我有哪些电脑」→ `list_machines`（可能为空）。
3. `make dev-desktop` 登录：设置→我的电脑应看到本机在线；再问「我有哪些电脑」。
4. 用户可见聊天/状态文案不出现「沙箱 / sandbox / 工作电脑 / `/workspace`」；工具状态如「列出目录」「写入文件」。
5. 「下载里最大的 mp4」应走 skill/`host_shell` 摘要，而不是数百条 `host_ls` entries（见本机查询设计验收）。
